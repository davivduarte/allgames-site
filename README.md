# 🎮 AllGames — Gaming Hub

Um hub interativo desenvolvido para reunir informações, imagens e curiosidades sobre os principais jogos do mundo dos games.

O **AllGames** apresenta uma experiência visual moderna, com tema escuro, elementos inspirados em plataformas gamers e uma seleção especial de 30 jogos populares, além de quizzes interativos para testar seus conhecimentos sobre o universo dos videogames.

## 🚀 Funcionalidades

- 🎯 **Catálogo com 30 jogos:** seleção de títulos populares, incluindo GTA V, GTA VI, CS2, Overwatch 2, Fortnite, Minecraft, Valorant e Red Dead Redemption 2.
- 🖼️ **Galeria de imagens:** capas e artes relacionadas aos jogos, com imagens adicionais na página de detalhes.
- ⭐ **Destaque GTA VI:** seção especial dedicada ao próximo lançamento da franquia Grand Theft Auto.
- 📖 **Descrições detalhadas:** informações sobre história, ambientação e jogabilidade dos títulos.
- 🧠 **Quizzes interativos:** perguntas sobre datas de lançamento, personagens, franquias e curiosidades.
- 🔎 **Pesquisa de jogos:** encontre seus títulos favoritos no catálogo.
- 🌐 **Integração com API:** utilização da IGDB para complementar informações e ampliar as possibilidades de pesquisa.
- 🎨 **Interface responsiva:** visual moderno, tema escuro e elementos inspirados no universo gamer.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- React
- Vite
- API IGDB

## ⚙️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/AllGames.git
```

Entre na pasta:

```bash
cd AllGames
```

Instale as dependências:

```bash
npm install
```

Configure as variáveis de ambiente no arquivo `.env`:

```env
IGDB_CLIENT_ID=sua_client_id
IGDB_CLIENT_SECRET=seu_client_secret
```

Inicie o servidor:

```bash
npm run dev
```

Acesse o endereço indicado no terminal para visualizar o projeto.

## 🎯 Objetivo do projeto

O AllGames foi desenvolvido com o objetivo de explorar conceitos de desenvolvimento web, integração com APIs, organização de componentes, manipulação de dados e criação de interfaces interativas.

Além de funcionar como um catálogo de jogos, o projeto busca proporcionar uma experiência imersiva para quem gosta de videogames.
